# 投票结果确认单自定义配置

## 目标
为每所高校提供一套统一的投票结果确认单模板。管理员可配置标题说明、结果字段、签字区域、版式和页脚，页面预览、打印/PDF 与 Word 导出保持一致。

## 实施内容

1. **保存全校统一模板**
   - 在学校资料中增加确认单配置，保存为结构化设置。
   - 提供完整默认模板，现有高校无需配置即可继续使用。
   - 仅本校管理员可读取和修改本校模板，继续保持高校之间的数据隔离。

2. **确认单配置界面**
   - 在“投票结果”页增加“确认单配置”区域，并提供实时预览。
   - 标题与说明：可编辑学校标题、确认单标题模板、人数统计说明、自定义说明文字。
   - 结果表字段：可勾选显示、修改列名、调整顺序；支持序号、姓名、单位、现职称、推荐、不推荐、弃权。
   - 签字区域：可增删签字项目、修改名称、设置行数、是否显示日期；默认包含主任委员、其他委员（三条集中签字线）、监票人。
   - 版式与页脚：可选纵向/横向、字号、表格疏密、页脚文字。
   - 支持恢复默认设置，保存后全校所有投票场次使用同一模板。

3. **统一确认单输出**
   - 把确认单抽成共用渲染逻辑，避免页面、打印和 Word 内容不一致。
   - 页面预览使用所选场次的实际数据与学校模板。
   - 打印/PDF 仅输出确认单本体。
   - Word 导出同步标题、说明、字段顺序和名称、签字区域、版式及页脚。
   - 对自定义文字进行安全转义，避免特殊字符破坏导出文件。

4. **验证**
   - 验证配置保存、刷新后保留、切换场次后沿用全校模板。
   - 验证其他委员显示多行长签字线。
   - 验证页面预览、打印视图与 Word 内容一致，并检查桌面与窄屏布局。

## 技术细节
- 数据库为 `schools` 增加 JSON 配置字段，由既有学校管理员权限规则保护。
- 前端以带版本的默认配置合并已保存设置，便于后续增加模板选项且不影响旧数据。
- 打印样式根据纸张方向生成；Word 使用同一份标准化配置和数据生成 HTML 文档。
