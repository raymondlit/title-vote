# 界面配置扩展：字体、字号、配色、显示模式与布局

## 目标
在现有「界面配置」中加入校级外观设置，并统一应用于本校登录页、管理后台和评委投票端。现有学校自动使用当前风格作为默认值，不影响已有数据与功能。

## 配置项
- **系统字体**：提供适合中文界面的预设字体栈，管理员可选择并实时预览。
- **字号**：小、标准、大三档，统一调整正文、标题和控件文字比例。
- **配色方案**：提供数套克制、易读的预设方案；保留自定义强调色，选择自定义时可调色。
- **显示模式**：浅色、深色、跟随系统三种模式；由学校管理员设置全校默认模式。
- **布局密度**：紧凑、标准、宽松三档，调整导航、页面、表单、表格与内容间距，不改变功能结构。

## 实现范围
1. 扩展学校配置数据，加入字体、字号、配色方案、显示模式和布局密度字段，并设置兼容现有界面的默认值。
2. 在界面配置页加入清晰的选择控件和实时预览；保存时与学校名称、校徽、副标题一起更新。
3. 建立统一的学校主题容器，把配置转换成语义化字体、字号、颜色和间距变量。
4. 学校专属登录页读取公开展示所需的外观字段；登录后的管理后台与评委端从当前学校配置读取并应用。
5. 深色与跟随系统模式覆盖背景、卡片、文字、边框和控件状态；配色预设保持足够对比度。
6. 保留现有极简视觉原则：无渐变、无装饰性阴影、细分隔线、小圆角。

## 验证
- 检查配置保存、刷新后保持，以及登录页/管理后台/评委端同步。
- 检查浅色、深色、跟随系统三种模式。
- 检查小/标准/大字号与紧凑/标准/宽松布局在桌面和窄屏下无文字溢出或遮挡。
- 检查未配置的新旧学校仍显示原有默认风格。

## 技术说明
- 配置存储在学校记录中；公开登录页只开放外观展示字段，不开放内部设置。
- 页面通过 CSS 变量与 `data-*` 属性应用主题，组件继续使用现有语义化颜色类。
- 跟随系统模式使用浏览器的系统明暗偏好，不保存个人选择。
