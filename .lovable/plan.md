# 职称评审推荐投票平台 — 第一期：管理后台

先建成完整的后台管理体系（超级用户 → 高校管理员 → 界面个性化 → 名单导入 → 分组与规则）。评委投票端、统计图表、签字单导出放在第二期。

## 视觉风格

原研哉式极简：大面积留白、无彩底（米白 #F7F6F3 / 纯白卡片）、极细分隔线、深灰墨色文字、单一低饱和强调色。无阴影、无渐变、圆角极小。中文正文用系统黑体（Noto Sans SC），标题字重克制，靠间距与排版建立层级，不靠色块。

## 第一期要做的事

### 1. 账号体系（三层）
- 超级用户：icelm@sina.com / 65928088Lit（系统内置，仅一个）
- 高校管理员：由超级用户创建，属于某所高校
- 评委：由管理员导入，第二期登录使用

### 2. 超级用户后台
- 高校列表：新增高校（名称、简称）
- 管理员管理：输入学校 + 姓名 → 自动生成用户名与随机初始密码，密码仅显示一次，附「复制」按钮
- 权限管理：每位管理员可勾选权限项（界面配置、评委管理、评审对象管理、分组与规则、结果查看），同一高校可有多个不同权限的管理员
- 可重置密码、停用管理员

### 3. 管理员后台
- **界面个性化**：学校名称、Logo 上传、副标题、强调色。保存后本校登录页、后台顶栏、（第二期）评委端同步显示本校信息
- **评委名单导入**：上传 Excel/CSV（姓名、工号、单位、职称、手机号），预览校验后入库，批量生成用户名与初始密码，可导出账号表一次
- **评委会职务**：设置主任委员、副主任委员；主任/副主任可对评委分组、指定组长或开启小组推选组长
- **评审类别**：可自由增删（高级、中级、非教师系列…）
- **学科小组**：可自由增删（工科组、理科组、文史组…），评委拖拽/勾选分组
- **评审对象导入**：上传 Excel/CSV（姓名、单位、申报类别、学科），按类别 + 学科自动分组，可人工调整
- **投票规则**：按「评审类别 + 学科小组」设置参评总人数、最多可推荐人数、是否允许弃权、是否必须对每人表态。规则在第二期投票提交时校验
- **登录页**：/school/{学校标识} 显示该校 Logo 与名称的个性化登录入口

## 技术说明

- 启用 Lovable Cloud 作为后端：数据库 + 登录 + Logo 文件存储
- 数据表：schools、profiles（用户档案，含 school_id）、user_roles（角色独立存表，superadmin/admin/judge）、admin_permissions、school_branding、review_categories、subject_groups、judges、judge_group_members、candidates、voting_rules
- 全部表启用行级安全：超级用户可见全部，管理员仅可见本校数据
- 生成账号与密码、导入名单等特权操作走服务端函数，并在函数内校验调用者角色
- Excel/CSV 解析使用 xlsx 库在浏览器端解析、服务端校验入库
- 密码为一次性生成的随机串，只在创建返回时明文出现一次，不再存储明文
