# 学科组线下推荐 + 大评审委员会

让学科组的推荐在线下完成：管理员在线设计并下载学科组推荐表格，线下投票填好后上传，系统录入「是否推荐 + 得票数」，推荐通过的人员自动进入大评审；评委管理里再勾选组建大评审委员会，开展线上投票。

## 一、评审对象菜单：学科组线下推荐

在「评审对象」页现有内容之下，新增一个板块「学科组线下推荐」，分三步排布：

**1. 表格设计与下载**
- 选择评审类别 + 学科小组，系统按该组的评审对象生成表格行。
- 可勾选表格栏目：姓名、单位、现职称、工号、备注；固定追加线下填写栏「是否推荐」「同意票数」「总票数」，并可自定义增删栏目（沿用现有模板设计交互）。
- 可编辑表头标题（如「XX学院高级职称学科组推荐表」）、副标题说明、页脚签字栏（组长签字、组员签字、日期）。
- 下载 Excel / CSV，或直接在线打印（可存 PDF），供线下会议使用。
- 设计与勾选结果记住，下次打开沿用。

**2. 上传录入**
- 上传填好的 Excel/CSV，页面先显示识别结果预览：姓名、是否推荐、同意票数、总票数，姓名对不上的行标红提示。
- 确认无误后入库，记录所属类别、学科小组、录入时间。
- 同一组重复上传时覆盖该组的旧结果，并提示。

**3. 结果一览**
- 按学科小组列出已录入结果：推荐/不推荐、票数、录入时间，可重新上传或清除。
- 标出「推荐通过」的人员，这批人即为进入大评审的名单。

## 二、评委管理：大评审委员会组建

在「评委管理」页新增「大评审委员会」板块：
- 从现有评委名单中勾选成员（支持搜索、按学科小组筛选、全选本页）。
- 为成员指定职务：主任委员 / 副主任委员 / 委员。
- 显示已选人数与职务统计，保存后成为该校的大评审委员会名册。
- 创建大评审场次时，投票范围可直接选「大评审委员会」，只有委员会成员能看到并参与该场投票。

## 三、投票场次衔接

- 「投票场次」页新增「创建大评审场次」：选类别后，自动把线下推荐通过的人员载入该场次作为评审对象，参与评委为大评审委员会成员。
- 投票规则、推荐名额提示、确认单等沿用现有逻辑，不变。

## 技术要点

- 新表 `offline_group_results`：school_id、category_id、group_id、candidate_id、is_recommended、agree_votes、total_votes、recorded_by、created_at；唯一约束 (session 维度上 category_id+group_id+candidate_id)；GRANT + RLS 按 `current_school_id()` / `is_school_admin()` 限制，service_role 全权。
- `judges` 增加 `is_committee_member boolean not null default false`，复用现有 `committee_role` 表示职务；迁移含 GRANT，不动既有策略语义。
- `vote_sessions.voter_scope` 增加取值 `committee`，vote.index / submitBallot 的范围校验同步支持。
- 表格生成与解析复用 `src/lib/sheet.ts`（parseSheet / downloadXlsx / downloadCsv / templateRowsFor），新增学科组推荐表字段定义与线下栏位。
- 上传入库与「载入大评审对象」走 `src/lib/admin.functions.ts` 的服务端函数，校验本校归属。
- 视觉沿用现有原研哉极简风格：Panel 卡片、极细分隔线、无阴影，与页面其他板块一致。
