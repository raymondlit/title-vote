# 高校管理员登录与身份鉴权专项测试

测试时间：2026-11-20（北京时间）。范围仅覆盖第一阶段，不包含名单导入或投票。

## 方法与数据隔离

- Playwright Chromium，1280×1800，每次独立浏览器上下文。
- 在独立临时高校创建真实管理员；通过学校登录页输入用户名、密码并点击登录，确认进入 `/admin`、显示本人姓名和权限。
- 浏览器访问 `http://localhost:8080`，认证与数据经本站 `/api/public/sb/` 中继访问真实托管服务；没有模拟成功响应。
- 等学校名称完成显示后输入；首屏准备时间额外包含400毫秒人为稳定等待，不作为产品首屏性能指标。
- 登录耗时：点击登录到“评审进度看板”标题可见；不代表全部后台统计加载完成。

## 速度结果

| 指标 | 改进前 | 改进后 |
|---|---:|---:|
| 正常登录成功 | 3/3 | 5/5 |
| 登录耗时（毫秒） | 1335.4、1333.9、1330.3 | 1335.6、862.2、855.0、851.9、849.2 |
| 登录中位耗时 | 1333.9 | 855.0 |
| 获取令牌中位耗时 | 419.8 | 386.2 |
| 获取身份信息中位耗时 | 496.2（取三路最慢请求） | 387.2 |
| 身份信息请求数 | 3 | 1 |
| 学校入口到看板相关请求总数 | 7 | 5 |
| 正常登录504响应 | 0 | 0 |

登录中位耗时减少约35.9%。优化后首次登录仍为1.336秒，因此不能承诺每次低于1秒；样本较少，不推导P95或并发容量。

## 诊断与已落地方案

1. 角色、学校归属、管理权限原为三个并行请求，仍受最慢请求拖累，基线最慢角色请求为829.8毫秒。新增 `get_current_account` 将本人身份合并为一次数据库读取。
2. 原预加载调用受保护页面，会执行登录门槛而不是可靠下载目标页面。改为只预载首页代码，不运行登录判断或提前读取受保护数据。
3. 原身份读取忽略查询错误，可能缓存缺失权限。现在任何失败或格式错误都拒绝缓存，允许用户立即重试，不把暂时故障误当作无权限。
4. 限流最后一次尝试失败后不再多等一次退避时间；意外网络异常恢复登录按钮并提示重试。未降低密码校验强度或改变身份访问规则。

## 身份与可靠性验证

- 匿名调用身份接口：拒绝。
- 错误密码：显示明确提示，不进入后台。
- 身份接口一次503：提示重试，第二次点击登录成功进入后台。
- 登录后整页刷新：保持本人身份，权限正常显示。
- 本校管理员查询其他高校：返回0行。
- 新接口只返回 `auth.uid()` 本人数据，没有可传入的其他用户参数；SECURITY INVOKER 保留原有行级权限。
- 四项新增单元测试验证角色来源、身份不匹配拒绝、无角色不授予权限、错误数据拒绝缓存；全套80项通过。
- 浏览器没有页面运行错误；最终自动检查显示 build OK。

## 清理与限制

- 通过现有超级管理员页面删除测试高校，验证学校、管理员资料、角色均无残留。
- 删除后原测试凭据登录失败，证明认证账号已删除；临时凭据文件已删除。
- 没有修改正式高校数据，没有关闭安全保护。
- 本次不是国内会场网络、手机或高并发压测；正式域名效果需发布后在现场复核，不能用本地预览测量替代。
- 本次不涉及后续导入、建场或投票阶段。
